# 작업 버튼과 엑셀 서식 보완 설계

## 범위

- 화면에서 `서석감사반 수임실적 대사` 문구를 삭제해 특정 감사반 전용으로 보이지 않게 한다.
- `대사 실행`, `Clear`, `새로고침` 버튼을 한 줄에 배치한다.
- 버튼은 참고 이미지처럼 짙은 네이비 바탕, 흰색 글자, 작은 원형 캡슐 형태와 절제된 그림자를 사용한다.
- Clear는 선택 파일, 분석 결과, 경고, 진행률과 필터를 초기값으로 되돌린다.
- 새로고침은 현재 페이지를 다시 불러와 전체 작업을 새로 시작한다.

## 글꼴

- 웹 화면의 글꼴 스택은 `함초롬돋움`, `나눔고딕`, `맑은 고딕`, `Noto Sans KR`, sans-serif 순으로 둔다.
- 다운로드 엑셀의 모든 사용 셀은 10pt를 기본 크기로 한다.
- XLSX 셀 스타일에는 단일 글꼴명만 기록할 수 있으므로 첫 번째 우선 글꼴인 `함초롬돋움`을 기록한다. 사용 PC에 해당 글꼴이 없으면 Excel의 글꼴 대체 기능이 적용된다.

## 검증

- 특정 감사반 문구가 렌더링 결과와 번들에서 제거된다.
- 세 버튼이 데스크톱과 모바일에서 한 줄을 유지한다.
- Clear 이후 파일 수가 0개이고 결과 영역이 초기 상태로 돌아간다.
- 생성된 `24년`, `25년` 시트의 사용 셀에 10pt와 `함초롬돋움` 스타일이 적용된다.
- 기존 데이터, 열, 필터, 틀 고정과 다운로드 파일명은 유지된다.

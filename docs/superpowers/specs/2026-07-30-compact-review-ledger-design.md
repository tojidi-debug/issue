# 독립성 검토 화면 간소화 설계

## 목표

사전감리 기준자료와 구성원 매출장을 한 화면에서 첨부하고 즉시 대사한 뒤, 모든 검토 후보를 클릭 없이 간결한 한 행 목록으로 확인한다.

## 화면 구조

### 1. 최소 헤더

- 작은 서비스명 `감사·인증 독립성 검토`만 표시한다.
- `파일은 브라우저 안에서만 처리됩니다`를 짧은 보조 문구로 함께 표시한다.
- 기존 문장형 소개, 장식 문자, 별도 원칙 띠는 제거한다.

### 2. 좌측 입력 영역

- 기준자료와 매출장 파일 첨부를 하나의 좁은 작업 패널에 배치한다.
- 각 첨부 영역은 제목, 허용 형식, 선택된 파일 목록만 보여준다.
- `대사 실행` 버튼과 진행률을 같은 패널 하단에 둔다.
- 긴 개인정보 안내와 반복 설명은 제거한다.

### 3. 우측 결과 영역

- 분석 전에는 필요한 두 종류의 파일을 안내하는 짧은 빈 상태를 표시한다.
- 분석 후에는 요약 수치, 필터, 결과 목록을 위에서 아래로 배치한다.
- 엑셀 다운로드 버튼은 결과 제목 줄에 둔다.

## 결과 목록

각 후보는 클릭·펼침 없이 하나의 행에 모든 정보를 항상 표시한다. 기존 13개 항목은 삭제하지 않고 다음 5개 묶음 열로 구성한다.

1. `위험·대상`: 위험도, 대상 구분, 매칭 회사
2. `전표`: 연도, 거래일자, 담당자, 원본 위치
3. `거래`: 품명·적요, 금액, 용역 분류
4. `대사 근거`: 확인 필요사항, 매칭 근거
5. `검토 비고`: 왜 확인해야 하는지와 필요한 증빙

셀 내부 텍스트는 필요한 경우 자연스럽게 줄바꿈할 수 있지만, 후보 하나는 항상 하나의 표 행으로 유지한다. 정보를 숨기거나 별도 상세 화면으로 이동시키지 않는다.

## 색상과 시각 체계

- 전체 바탕은 거의 흰색으로 유지한다.
- 테두리는 가는 청회색 선만 사용한다.
- 동일한 확인 사유는 동일한 매우 연한 파스텔 배경으로 구분한다.
  - 재무제표 작성지원·회계자문: 연한 하늘색
  - 기장·기업진단 동시수행: 아주 연한 회색
  - 가치평가·자산 양수도: 연한 민트색
  - 기타 재무영향 컨설팅: 연한 살구색
- 위험도는 작은 텍스트 배지로만 표시하고 행 전체를 강한 빨강·노랑으로 칠하지 않는다.
- 그림자, 그라데이션, 큰 장식 요소는 사용하지 않는다.

## 스크롤과 반응형

- 데스크톱에서는 좌측 입력 패널과 우측 결과 영역을 나란히 배치해 첫 화면의 세로 스크롤을 최소화한다.
- 결과가 많을 때만 결과 목록 내부에 세로 스크롤을 둔다.
- 가로 스크롤은 우선 피하고, 작은 화면에서 모든 필드를 보존하기 위해 필요한 경우에만 결과 목록 내부에 허용한다.
- 스크롤바는 흰색 바탕과 옅은 청회색 손잡이로 표시한다.
- 모바일에서는 입력과 결과를 위아래로 배치하되 기능과 필드를 숨기지 않는다.

## 동작과 데이터 처리

- 기존 PDF, XLS, XLSX, CSV 다중 업로드와 브라우저 내 분석 로직을 그대로 유지한다.
- 기존 독립성 판정 기준, 필터, 엑셀 내보내기 기능을 변경하지 않는다.
- 경고는 입력 패널 안에 짧은 목록으로 표시한다.
- 처리 실패 파일은 파일명 옆 상태로 명확히 표시한다.

## 오류 처리와 접근성

- 파일이 없으면 실행 버튼을 비활성화한다.
- 지원하지 않는 형식은 추가하지 않고 허용 형식을 짧게 안내한다.
- 키보드 포커스와 상태 텍스트를 유지한다.
- 색상만으로 사유와 위험도를 구분하지 않고 텍스트를 함께 표시한다.

## 검증 기준

- 기존 단위 테스트가 모두 통과한다.
- 린트와 GitHub Pages 정적 빌드가 통과한다.
- 데스크톱 첫 화면에서 헤더, 파일 입력, 실행 버튼, 결과 시작 부분이 불필요한 긴 페이지 스크롤 없이 보인다.
- 모든 후보 행에서 기존 13개 정보가 클릭 없이 확인된다.
- 같은 사유의 행은 같은 파스텔 배경을 사용한다.
- 공개 GitHub Pages가 로그인 없이 HTTP 200으로 응답한다.

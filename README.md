# 감사·인증 독립성 검토

사전감리자료, 수임신고 대사와 감사반 구성원 전체의 매출장을 브라우저 안에서
대사하여 독립성 관련 증빙을 다시 확인할 전표를 선별하는 웹앱입니다.

## 주요 기능

- PDF, XLS, XLSX, CSV 다중 업로드
- 사업자번호 우선, 회사명 보완 방식의 감사·인증 대상회사 대사
- 기업진단 회사와 모든 구성원의 기장업무 동시수행 후보 탐지
- 허용되는 세무조정·세금신고 업무 제외
- 회계처리자문, 재무제표 작성지원, 수정분개, 가치평가·자산양수도 등 분류
- 확인 이유와 필요한 증빙을 포함한 검토 후보 표
- `24년`, `25년` 시트로 구성된 `매출 확인.xlsx` 다운로드
- 업로드 파일을 서버로 전송하거나 브라우저에 영구 저장하지 않는 로컬 처리

## 개발 명령

```text
npm install
npm test
npm run lint
npm run build
npm run dev
```

검토 결과는 독립성 위반을 확정하는 것이 아니라 계약서, 세금계산서, 수행기간과
산출물을 추가 확인할 후보를 제시합니다.
